# API Contracts Repository (`api-contracts`)

Single source of truth for all versioned gRPC Protobuf specs, AsyncAPI schemas, and OpenAPI definitions across FactoryOS.

```
api-contracts/
├── proto/
│   ├── factoryos/
│   │   ├── production/v1/
│   │   ├── warehouse/v1/
│   │   ├── quality/v1/
│   │   └── maintenance/v1/
├── asyncapi/
│   ├── events/
└── openapi/
    ├── v1/
```
