# FactoryOS Strategic Milestones & Evolution Roadmap

---

## 🎯 Milestone 1: Physical Ontology & Telemetry Ingestion Core
* Focus: Establish ISA-95 Asset Hierarchy, Edge Collector Runtime (OPC-UA/MQTT), TimescaleDB Historian, and Real-Time OEE Metrics Engine.
* Primary RFCs: `RFC-0001`
* Key Deliverable: Real-time OEE Observability Dashboard for shop-floor machinery.

---

## 🎯 Milestone 2: Guided Digital Execution & Lot Traceability
* Focus: Operator UI Terminal, Work Order Routing State Machine, Component Scan Verification, and Lot Genealogy Graph.
* Primary RFCs: `RFC-0002`, `RFC-0003`
* Key Deliverable: End-to-end station execution & instant recall capability.

---

## 🎯 Milestone 3: Reactive Closed-Loop Quality & Maintenance
* Focus: Automated Quality NCR dispatch, Preventive Maintenance (PM) schedules, CMMS incident ticketing.
* Primary RFCs: `RFC-0004` (TBD), `RFC-0005` (TBD)
* Key Deliverable: Automatic station hold on quality failure & instant technician dispatch.

---

## 🎯 Milestone 4: Finite Capacity Scheduling & Edge Resilience
* Focus: Dynamic station re-routing, finite capacity scheduling optimization, offline edge execution buffer.
* Primary RFCs: `RFC-0006` (TBD)
* Key Deliverable: Autonomous plant operation during network cloud disconnects.

---

## 🎯 Milestone 5: Enterprise Multi-Plant Control Tower & Industrial AI
* Focus: Multi-site aggregated analytics, predictive maintenance AI, open developer plugin ecosystem.
* Primary RFCs: `RFC-0007` (TBD)
* Key Deliverable: Enterprise-level manufacturing intelligence tower.
