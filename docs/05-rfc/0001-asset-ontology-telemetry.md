# RFC-0001: Asset Ontology & High-Frequency Telemetry Ingestion Engine

* **Author(s):** Ray Doan
* **Status:** Draft
* **Target Release:** Milestone 1

---

## 1. Problem Statement
Factories generate thousands of raw signals per second from PLCs, CNC machines, and IoT sensors. We need a unified physical asset ontology and high-throughput ingestion edge runtime to process signals, calculate OEE real-time, and store time-series data.

---

## 2. Goals & Non-Goals

### Goals
- [ ] Define ISA-95 Asset Hierarchy model (Site, Area, Line, Station, Sensor).
- [ ] Implement store-and-forward SQLite buffer on Edge Agent for offline resilience.
- [ ] Compute real-time OEE (Availability, Performance, Quality) metrics.
